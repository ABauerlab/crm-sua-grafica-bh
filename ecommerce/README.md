# Loja Sua Gráfica BH (suagraficabh.com.br)

Next.js 15 (App Router) isolado do CRM. Lê só a vitrine pública `ecommerce_products` do Supabase com a chave publicável.

- Rodar: `cp .env.example .env.local` (preencha a chave publicável) e `npm run dev` (porta 3001).
- Hostinger: app Node.js, Base Directory `ecommerce/`, build `npm run build`, start `npm start`, Output Directory `.next`, variáveis do `.env.example`.
- Roteiro das fases e regras: `../docs/ecommerce.md`.
